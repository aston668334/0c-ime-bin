# 0c-ime-bin

Unmodified Windows installer for 靈犀注音 (0c-ime), downloaded from the official site <https://0c.biggo.com/download/>.
This is **not** the official distribution; use the upstream project ([0c-biggo/0c-ime](https://github.com/0c-biggo/0c-ime)) for support and the latest version.

- Releases: see the [Releases](https://github.com/aston668334/0c-ime-bin/releases) page. The installer is too large for git, so it is a release asset.
- Current mirror: **v0.2.6** (`0c-0.2.6-windows-amd64-setup.exe`, with its `.sha256`).
